# Карта 2ГИС и работа без интернета

## Что изменилось

- Вместо прежнего внешнего сервиса плиток используется российский сервис **2ГИС**.
  Браузер обращается только к локальному прокси `/tiles/{z}/{x}/{y}.png`,
  а сервер при необходимости скачивает плитку с `MAP_TILE_UPSTREAM` и
  кэширует её на диске в `data/tiles`.
- Видимая атрибуция — `© 2ГИС`. Префикс Leaflet отключён во всех картах.
- Leaflet 1.9.4 и Bootstrap 5.3.3 положены в `static/vendor/`: ни один
  шаблон не тянет внешние CDN или сторонние серверы плиток.
- Service worker (`/sw.js`) кэширует приложение, статику, плитки и ответы
  `/fe/api/map_data`. При потере сети карта продолжает открываться,
  масштабироваться, показывать метки и всплывающие подсказки.
- На экране `/fe/` появился индикатор «Карта: офлайн-кэш готов (N тайлов)».

## Быстрый запуск

```bash
python -m pip install -r requirements.txt
python mock_api.py          # терминал 1: заглушка API на 127.0.0.1:5001
python app.py               # терминал 2: приложение на 127.0.0.1:8000
```

Откройте `http://127.0.0.1:8000/login?next=%2Ffe%2F`, войдите как
`doctor / demo12345`. Дайте странице 10–30 секунд: service worker
предзагружит область Сочи (`MAP_PRECACHE_BBOX`) на зумах 11–13
(≈ 412 плиток) и два набора точек карты (`view=all`, `view=nearest`).
После надписи «офлайн-кэш готов» интернет можно отключать.

## Серверный предзагрузчик

Если нужно подготовить диск-кэш ещё до запуска браузера:

```bash
python tools/fetch_tiles.py
python tools/fetch_tiles.py --zooms 11-14 --workers 16 --overwrite
```

Он кладёт файлы в `data/tiles/{z}/{x}/{y}.png`; `/tiles/...` отдаёт их
сразу, без обращения к 2ГИС.

## Переменные окружения

Добавьте в `.env` при необходимости:

```dotenv
MAP_ENABLED=1
MAP_TILE_URL=/tiles/{z}/{x}/{y}.png
MAP_ATTRIBUTION=© 2ГИС
MAP_ZOOM=16
MAP_TILE_UPSTREAM=https://tile2.maps.2gis.com/tiles?x={x}&y={y}&z={z}
MAP_TILE_CACHE_DIR=data/tiles
MAP_PRECACHE_BBOX=43.40,39.30,43.95,40.00
MAP_PRECACHE_ZOOMS=11-13
```

`MAP_TILE_URL` — то, что видит браузер. Менять его на внешний адрес не
нужно: иначе service worker не сможет кэшировать плитки по origin'у
приложения. `MAP_TILE_UPSTREAM` — адрес, откуда сервер скачивает плитки;
`{x}`, `{y}`, `{z}` подставляются только целыми числами из маршрута.

## Что проверено в демо-видео

1. Вход в `/fe` под врачом.
2. Список вызовов и сортировка «Ближайший вызов».
3. Карта 2ГИС с метками, плавное приближение и карточка вызова.
4. Переход в офлайн: тайлы, метки и попапы продолжают работать.
5. Возврат в онлайн: отложенная форма записи на приём отправляется сама.
6. Запись появляется в карточке пациента. Звук в ролике отключён.

## Юридическое примечание

Публичный endpoint 2ГИС используется здесь для демонстрации офлайн-схемы.
Для промышленной эксплуатации нужно получить права на использование
плиток 2ГИС (или указать свой лицензированный `MAP_TILE_UPSTREAM`).
